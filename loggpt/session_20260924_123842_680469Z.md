## Results (all VERIFIED from bytecode + runtime execution of the real jar)

### Load chain
- NPC: `main.b.a.a.y.a(lang)` ; Monsters: `main.b.a.a.v.a(lang)`
- Both call `main.b.a.a.e.a(name)` → `e.b` path resolve (`conf/`|`assets/`|raw via
  Gdx.files.internal) → bytes → `main.b.a.a.f.a(bytes)`:
  - plaintext markers (`ver_vn`/`ver_cn`/`ver_e`/`name_vn`/`MountID`) → passthrough
  - else AES/ECB/PKCS5Padding (fallback PKCS7Padding), key ASCII
    `1234567812345678`; on failure CSV heuristic (≥3 commas, ≥1 newline in first
    min(len,2048)) else null
  - UTF-8 decode; strip leading U+FEFF
- `H.a` strips BOM + trailing CR; `H.b` splits on `,`; `H.c` maps `;` and `|` → `,`

### Formats (decoded header row, runtime)
- zsNpc: ≥13 fields; key=ModelID (e.g. n420001); value[12]=name/title/hello/chat
  × vn/cn/en. Accessors y.b/c/d/e = name/title/hello/chat (hello+chat pass H.c).
  Header: `ModelID,name_vn,name_cn,name_e,title_vn,title_cn,title_e,hello_vn,hello_cn,hello_e,chat_vn,chat_cn,chat_en`
- zsMonters: ≥4 fields; key=ModelID (e.g. m510101); value[3]=name vn/cn/en.
  Header: `ModelID,name_vn,name_cn,name_e`
- Accessor lang fallback: default VN; ver_cn→cn if nonempty else VN; ver_e→en if
  nonempty else VN. `y.b()`/`v.b()` map config `blnLanguage` 0/1/2 →
  ver_vn/ver_cn/ver_e (assets conf has blnLanguage=0).

### Callers
- `main.b.a.a.n` startup: lang from blnLanguage switch → y.b/v.b then y.a/v.a

- `main.b.a.c.al` language switch UI: y.a/v.a reload (aload_3 = lang)
- `main.b.a.g.g` / `g.i` localized display lookups (y.b/c/d/e, v.b)
